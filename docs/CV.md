# Trois propositions pour le CV

- Développement et exécution d'un pipeline MLOps de churn sur 7 043 observations IBM Telco : validation, prétraitement sans fuite, comparaison de trois modèles et suivi des expériences avec registre MLflow.
- Déploiement local Python d'une API FastAPI et d'une interface Streamlit pour prédictions individuelles et CSV ; ROC-AUC test 0.832 et rappel 90.1% au seuil 0.17, avec validation stricte et export des résultats.
- Mise en place de 17 tests automatisés, contrôles Ruff, logs structurés et détection de dérive par PSI ; préparation de Docker Compose, GitHub Actions et d'une procédure de livraison avec retour arrière.

Ne pas ajouter « déployé dans le cloud », « Docker validé » ou « CI exécutée sur GitHub » : ces actions n'ont pas été réalisées. Les chiffres concernent le benchmark réservé, pas une mesure de production.
